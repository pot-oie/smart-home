# 上课后需要确认与实现

> 2026-10-28状态提示：本文保留早期逻辑接口与接入规划；STM32F103C8T6、温湿度/光照及RFID已有实测，USB转TTL单向上传已通。这里的完整消息/请求接口尚未全部落实到实物，当前状态及接手步骤见[开发交接文档](../../../HANDOFF.md)。

客户端已选 Flutter；现阶段不预设通信硬件、MCU 具体型号和引脚，不开发虚构 STM32 驱动。

需要记录：

1. STM32 完整料号、开发板、供电、电平、下载器和现有课程工程。
2. 温湿度、光敏、RFID 的具体型号与接口；温湿度最短采样周期、光敏 AO/DO 和亮度极性、RFID 标识格式。
3. 人体红外、震动、火焰、燃气、水接触模块是否领取，预热与触发极性；扩展器件可以停用。
4. 有无 BLE/Wi-Fi 模块、模块型号与固件能力，是否允许增加通信桥接；根据课堂条件选择一条路线。
5. 现场采集周期、恢复区间、有限缓存容量、断连重试与协议上限。

后续步骤：独立验证采集 → 在 STM32 实现现场规则、RFID 和调度 → 定义字节帧/校验/请求与 ACK → 实现 `DeviceAdapter` → 真机联调 → 报告测试结果。

真实 BLE/Wi-Fi 权限、扫描、配对/联网、发现、重连和配置读取均尚未实现。手机平台确定后，分别验证 Android/iOS 的权限、生命周期与连接行为。

云端远程访问、摄像头与 AI 推理未进入基础范围。没有舵机、电机、电锁或实体窗帘的驱动和动作反馈。
