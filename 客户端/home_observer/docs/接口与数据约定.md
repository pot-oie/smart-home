# 客户端接口与共享数据

首版只定逻辑数据约定，实物通信未选择，不承诺串口波特率、BLE 服务 UUID、Wi-Fi 端口或帧校验算法。

## 设备适配接口

`DeviceAdapter` 提供 `sourceName/isSimulation/connected/messages/start/send/receipt/close`。页面不直接访问芯片或网络。未来通信适配器将接收字节流解码并验证，转换成当前共享模型；控制器据请求编号匹配结果，据事件编号与 revision 合并。

消息类别：`snapshot`（当前样本与软件状态）、`event`（安全事件）、`rfid`（刷卡结果）、`result`（请求处理结果）、`connection`（连接变化）。未知类别忽略。构建共享模型前，真实适配器必须校验字段、数值有限性、模块编号、版本与时间语义，不能把未经校验的网络 JSON 直接强制转换给控制器。

## 模块

1 温度；2 湿度；3 光敏；4 RFID；5 人体红外；6 震动；7 火焰；8 燃气；9 水接触；10 空气质量；11 声音；12 土壤湿度；13 倾斜；14 距离。

启用表只是模拟配置，不证明领取了这些器件。未启用模块值为 null，不参与规则。启用但无数据模拟驱动的扩展模块显示初始化；未来可增加独立驱动而不改页面结构。

`Sample`: id/value/quality/sampledAt。quality 为 valid/invalid/stale/disabled/initializing。过 5 秒未更新或断连时，valid 样本在当前页面按 stale 处理；陈旧值不显示成正常零，历史保留采样时的有效性。光强为相对量，气体为原始提示量，无 lux/ppm 标定结论。

`Snapshot`: bootId/seq/at/samples/curtainOpen/gateOpen。bootId 区分设备会话，seq 在会话内递增；重复或倒序快照不覆盖当前状态。模拟时间来自本机。真实端若无时钟同步，应上传 uptime/序号，并由适配器分开记录接收时间及发生时间，不能把接收时间当精确现场发生时间。

## 事件与请求

事件字段：eventId/moduleId/label/revision/triggeredAt/recoveredAt/acknowledgedAt。恢复与确认合并后才 complete；持续异常沿用 eventId，增加 revision。receipt 是传输接收确认，不能写 acknowledgedAt。未知、无效、未启用的现场输入不能产生恢复。

请求 JSON 示例（逻辑层）：

```json
{"version":1,"kind":"request","requestId":"app-session-1","action":"settings","args":{"tHigh":30}}
```

action=settings/ack；ack 的 args 为 eventId。设置需设备端原子验证全部字段，回传 requestId、accepted/reason，以及已接受 config。App 的期限默认 4 秒；只有对应 pending 请求能更新设置，超时后的迟到结果不自动改成成功。实际设备可能已经应用但结果丢失，联调时须增加配置读取/核查流程，再人工重提。

模拟端支持 32 个近期请求结果缓存：同一 requestId 返回原结果，不重复产生副作用。它用定期事件更新与断连队列模拟传输，128 条关键消息，满时淘汰最早项并计数；真实端 ACK 重试、帧校验、拆包粘包、蓝牙分片等必须在硬件路线确认后实现并单独测试。

## 行为

温湿度分别持续越界；默认持续 3 秒，回到上下限内缩的恢复区间才恢复，无效/陈旧中断持续条件。窗帘高光强关、低光强开，中间保持，自动无效时暂停；手动仍走请求接受结果。

布防仅抑制活动类新提示，不关闭独立危险提示，也不会因撤防直接清除已有事件；已有活动事件可随有效“无活动”恢复。

RFID 拒绝未知卡、读卡失败、模块不可用、名单不可用和停用卡；同卡 2 秒内抑制，授权通行窗口 5 秒。成功不撤防，不确认安全事件。所有通行/窗帘均为软件模拟。
