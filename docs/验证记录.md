## 后续 RFID 与 USB 转 TTL 实物联调

同日后续完成RC522兼容模块（版本0x82）的实际UID读取，增加USART1 PA9主动上传、USB转TTL串口接收与安卓模拟器真实卡号显示。运行接收端只依赖Python3标准库，不调用ST工具或ELF；ST-LINK当前仅保留主控供电。真实授权名单和Wi-Fi透传仍未接入。

- UART固件构建通过：Flash13468B、RAM2216B；已实际备份、烧录并独立逐字节回读验证。
- Python串口协议与伪终端收发/断线测试6项通过。
- 本轮客户端数据解析测试4项通过；Flutter analyze无问题，ARM64 Android Debug APK构建通过。
- 实物USB转TTL以9600 8N1接收到CRC校验通过的持续上传帧，安卓实际页面显示真实卡号。
- 暂停Mac接收服务9秒后页面隐藏旧卡号，恢复后自动更新；本轮没有单独验收物理USB拔插恢复。
